# 项目背景
用途：
检测 AGV 经过光电开关的事件，并通过 USB CDC 发送给 PC。
用于统计AGV的通过节拍间隔。
基本架构是  欧姆龙E3Z-R61光电开关 —— STM32 —— PC电脑
这个项目文件夹是其中PC程序部分，用于接收STM32的数据、统计并目视化在界面上



# 界面需求
界面式样如下。
┌──────────────────────────────────────────────┐
│ AGV 节拍测量                   COM3 [已连接]  │
├──────────────────────────────────────────────┤
│ 目标节拍： 80.0 s         [测量中]   [清空]    │
├──────┬──────────┬──────────┬────────────────┤
│ No.  │ 时间戳   │ 节拍(s)   │ 偏差(s)         |  
├──────┼──────────┼──────────┼─────────────────┤
│ 01   │ 00:35:01 │ 79.8    │ -0.1           │
│ 02   │ 00:36:22 │ 81.1    │ +1.1           │
│ ...                                          │
├──────────────────────────────────────────────┤
│ 测量次数 38       平均 80.2 s       CSV保存 │
└──────────────────────────────────────────────┘
- 其中`目标节拍`是人为输入的，仅作为下方偏差的计算。
- COM3应当是个下拉单选框，给用户选择STM32的COM口
- [已连接]/[未连接]是与STM32的通讯状态
- [测量中]/[停止中]是有STM32发送过来的，详见通信协议。
- [清空]是按钮，清空下面所有数据
- 时间戳的格式是24 小时制 HH:mm:ss.s，秒保留 1 位小数，例如 14:32:18.7，由STM32的timestamp转换得来。
- 节拍和偏差同样保留1位小数。
- 如果没有填入目标节拍，则偏差打“--”代替
- CSV保存只保存NO. 、时间戳、节拍、偏差这4个字段就可以了。不用保存测量次数和平均
- No. 纯粹是测量的序号。由于程序无法知道实际AGV的序号和总台数，对应的数据处理由人工自行完成。


# 技术栈
- 使用python 3.12
- 使用pyside6作为GUI
- 使用uv作为包和虚拟环境管理器、
- 串口通信采用Python 的 pyserial，而不是使用 Qt 的 QSerialPort。以分离逻辑。
